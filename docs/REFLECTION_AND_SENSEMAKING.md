# Refleksi dan sensemaking

Sediakan refleksi tingkat artefak, kompetensi dan longitudinal. Mahasiswa dapat mulai secara mandiri atau menanggapi pemicu berversi seperti bukti baru, ketidaksesuaian, gap, intervensi, milestone, dan sesi coaching. Workspace menampilkan ekspektasi, bukti yang dapat diakses, tren, feedback, tujuan terdahulu dan prompt. Mahasiswa menyusun interpretasi dan dapat mengoreksi pemahamannya.

Ringkasan otomatis menyimpan referensi bukti, waktu dan asal pembentukan. UI memberi label ringkasan sistem dan menampilkan narasi mahasiswa dengan atribusi tersendiri. Tautan refleksi mendukung beberapa bukti, kompetensi, feedback, keputusan dan tujuan. Revisi menyimpan rangkaian perubahan. Dialog coaching terikat relasi aktif dan mendukung tanggapan berurutan serta kesepakatan tindak lanjut.

Draf privat tersedia bagi pemilik. Pembimbing menerima akses berdasarkan pemberian eksplisit dan relasi berlaku. Peninjauan formal memerlukan otorisasi tersendiri. Terapkan kebijakan yang sama pada dashboard, ekspor, API dan akses lampiran. Refleksi menjadi bukti asesmen hanya bila ada kriteria eksplisit untuk kompetensi reflektif.
